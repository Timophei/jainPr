# Распознавалка первички → 1С

Веб-приложение для распознавания сканов входящих документов (УПД, счёт-фактура, ТОРГ-12, товарная накладная)
через OpenAI и подготовки файла загрузки в 1С.

**Как работает:**
1. Перетащить пачку сканов (JPG, PNG, PDF, TIFF) — по одному или сразу много.
2. Каждая страница уходит в модель OpenAI (vision + Structured Outputs), страницы одного документа склеиваются сами
   (продолжение таблицы без шапки или тот же номер документа).
3. Слева — исходный скан (масштаб, сдвиг, поворот), справа — та же таблица в редактируемом виде.
4. Движок проверок подсвечивает важное:
   - ⛔ кол-во × цена ≠ сумма, сумма + НДС ≠ всего, НДС не соответствует ставке;
   - ⛔ итог по строкам ≠ «Всего к оплате»; нет итоговой строки или пропущены номера строк (не загружена страница);
   - ⛔ ИНН не проходит контрольную сумму, нет номера/даты, документ уже выгружали (дубль);
   - ⚠ покупатель — не наша организация, необычная ставка НДС, дата в будущем / старше года;
   - ⚠ жёлтый пунктир — модель сама не уверена в ячейке (смазано, 3/8, 1/7);
   - ⚠ номенклатура не найдена в справочнике 1С или подобрана «по похожести».
5. Номенклатура сопоставляется со справочником 1С: по запомненным ручным выборам (ИНН поставщика + код/название),
   по артикулу, нечётко по названию (с проверкой размеров/чисел). Ручной выбор запоминается навсегда.
6. Выгрузка: XLSX на документ (лист «Товары» + лист «Документ»), ZIP по пачке, XML со всеми документами.

## Требования

- PHP 8.1+ (на сервере 8.3-FPM): расширения `curl`, `gd`, `zip`, `mbstring`, `fileinfo`, `xmlwriter`, `simplexml`
- `poppler-utils` (pdftoppm) — для PDF
- `imagemagick` — только если будут TIFF/HEIC
- Ключ OpenAI. **Если сервер в РФ — нужен прокси или OpenAI-совместимый шлюз** (OpenAI режет российские IP), см. `config.php`.

```bash
apt install php8.3-curl php8.3-gd php8.3-zip php8.3-mbstring php8.3-xml poppler-utils
```

## Установка (рядом с сайтами на gorodchaya.ru)

```bash
cd /var/www
git clone https://github.com/Timophei/jainPr.git raspoznavalka
cd raspoznavalka
cp config.example.php config.php   # вписать ключ, модель, пароль, прокси, ИНН своих организаций
chown -R www-data:www-data data
chmod 640 config.php && chown root:www-data config.php
```

Корень сайта — папка **`public/`**. `data/` и `config.php` лежат вне веб-корня и наружу не видны.

### nginx (отдельный поддомен, например scan.gorodchaya.ru)

```nginx
server {
    listen 80;
    server_name scan.gorodchaya.ru;
    root /var/www/raspoznavalka/public;
    index index.php;

    client_max_body_size 60m;

    location / { try_files $uri $uri/ /index.php; }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
        fastcgi_read_timeout 300;   # распознавание страницы может идти до минуты+
    }
}
```
Затем `certbot --nginx -d scan.gorodchaya.ru`.

### PHP-FPM (`/etc/php/8.3/fpm/php.ini` или pool-конфиг)

```ini
upload_max_filesize = 50M
post_max_size = 60M
max_execution_time = 300
```
Большие фото браузер сам ужимает до 2400 px перед загрузкой, так что лимиты нужны в основном для PDF.

## Тестовый режим

`'mock' => true` в `config.php` — распознавание не ходит в OpenAI, а возвращает пример (УПД на 11 строк),
чтобы проверить интерфейс и выгрузку.

## Справочник номенклатуры 1С

В 1С: Номенклатура → Ещё → Вывести список → сохранить как XLSX (или CSV). Нужны колонки «Наименование»,
желательно «Артикул» и «Код». Загрузить кнопкой «📚 Номенклатура 1С». Можно обновлять сколько угодно раз,
запомненные соответствия сохраняются.

## Загрузка в 1С

**XLSX:** в документе «Приобретение товаров и услуг» (УТ 11 / КА 2 / ERP) или «Поступление (акт, накладная, УПД)» (БП 3.0)
на вкладке «Товары» → «Загрузить из файла» → выбрать файл, сопоставить колонки (Номенклатура / Артикул, Количество, Цена, Сумма, Ставка НДС).
Шапку (поставщик, номер, дата) — с листа «Документ».

**XML (`documents.xml` в ZIP):** полная структура документов пачки — под внешнюю обработку 1С, которая создаёт документы
поступления целиком (ищет контрагента по ИНН, номенклатуру по коду/артикулу). Обработку можно написать следующим шагом.

## Устройство

```
public/index.php      интерфейс (+ вход по паролю)
public/api.php        JSON API
public/assets/        app.js (вся логика интерфейса и проверок), app.css
src/Recognizer.php    промпт и JSON-схема для OpenAI, тестовые данные
src/OpenAiClient.php  Responses API + Structured Outputs, ретраи, прокси
src/Ingest.php        приём файлов: PDF→страницы, EXIF-поворот, уменьшение
src/DocBuilder.php    склейка страниц в документы
src/Catalog.php       справочник 1С и сопоставление номенклатуры
src/Exporter.php      XLSX / XML / ZIP, реестр выгруженных (защита от дублей)
src/Xlsx.php          запись/чтение xlsx без библиотек
data/                 пачки, картинки, справочник, соответствия (не в git)
```
